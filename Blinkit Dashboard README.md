# 🛒 Blinkit Sales Analysis Dashboard

An interactive sales dashboard developed using Excel to analyze Blinkit sales data and generate business insights through visual reports.

This project focuses on data cleaning, analysis, and visualization using Excel dashboards.

---

## 📌 Project Overview

The dashboard provides insights into:

- Sales performance
- Product category analysis
- Outlet performance
- Customer purchasing trends
- Revenue insights

The dashboard helps understand business performance through interactive visualizations.
