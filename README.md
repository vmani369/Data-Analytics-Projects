# 🏏 IPL Data Analysis Dashboard

An interactive IPL Dashboard created using Excel to analyze Indian Premier League match and player data through visual reports and dashboards.

The project focuses on transforming raw cricket data into meaningful insights using data cleaning and visualization techniques.

---

## 📌 Project Overview

This dashboard helps analyze:

- Team performance
- Match results
- Player statistics
- Season trends
- Venue analysis
- Toss impact on matches

The dashboard provides easy-to-understand visual insights for IPL data analysis.

---

## 🚀 Features

✅ Team-wise Performance Analysis  
✅ Top Players Statistics  
✅ Match Winning Trends  
✅ Venue-wise Insights  
✅ Toss Decision Analysis  
✅ Interactive Charts & Visualizations  
✅ Clean and User-Friendly Dashboard  

---

## 🛠️ Tools & Technologies Used

- Microsoft Excel
- CSV Dataset
- Data Cleaning
- Data Visualization

---

## 📊 Dashboard Insights

- Total matches played by teams
- Win percentage analysis
- Top run scorers and wicket takers
- Venue performance comparison
- Toss winner vs match winner analysis
- Season-wise trends

---

## 📂 Dataset Used

The dataset contains:

- Match details
- Team information
- Player statistics
- Venue records

Dataset format: CSV
